# MODIS data for the Nile Delta

Upload folder for the team's MODIS files (started by Hussain).

- Small files the demo needs offline (CSV summaries) can go here.
- Large rasters (GeoTIFFs) should not go into git: GitHub rejects files over 100 MB and the repo gets slow. Agree a shared location with Tarek and note it in [`../NOTES.md`](../NOTES.md).
- AppEEARS request files (`*-request.json`) contain the requester's email: do not commit them.
- Add each dataset to [`../catalog.yaml`](../catalog.yaml).
